# 0.4.0 release checks, 2026-09-26

What was run before tagging 0.4.0, and what it does not prove.

## Run

- Biome, the frontend suites (690), the script tests, the backend suite (525), the production build and the
  dependency audits: all pass, no advisory.
- Contract validations `extender`, `frontend-backend`, `sandbox-runtime`, `sandbox-tablet`, `visual-servoing` and
  `petanque-parity`: all pass.
- `npm run qa:review`, `npm run visual:smoke`, `npm run e2e:builder` (11/11): pass.
- `npm run e2e:sim -- --robot explorer`: 30/30, against cartesian_manager `main` (d9a1fa5) and qontrol `91309cc`.
  The first run was 29/30: the new app-scoped policy narrowed the deployment's `/ui/` namespace against the Widget
  Lab's gesture topic literally and refused it. Fixed in `4352416`, then 30/30.
- `npm run e2e:sim -- --robot kinova`: 30/30, against the same manager and qontrol `a6382c1` (restored to `91309cc`).
- Production settings refuse to start without auth, with ownership disabled, with a short or shared key, and with a
  `*` origin.

## Not proven

- Nothing here ran on an arm or on the lab tablet. The STOP-at-press latch, the camera reconnect and the scan and
  dwell role switch are verified in unit tests and simulation only.
- The camera stale badge and reconnect were not exercised with a real camera dropping out.
- The tablet touch mapping still waits for its check on the tablet (`--diagnose`, the virtual touchscreen, the replug).
